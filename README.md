# React + Tailwind Starter (Vite)

A minimal, production-ready starter for React + Tailwind CSS using Vite.

## Quick Start

1. **Install dependencies**
   ```bash
   npm install
   # or
   pnpm install
   # or
   yarn
   ```

2. **Run the dev server**
   ```bash
   npm run dev
   ```

3. **Build for production**
   ```bash
   npm run build && npm run preview
   ```

## What's inside

- ⚡ Vite
- ⚛️ React 18
- 🎨 Tailwind CSS 3
- 🔧 PostCSS + Autoprefixer

## Tailwind config

Tailwind scans:
- `index.html`
- `src/**/*.{js,ts,jsx,tsx}`
